This is a plain **Markdown** post, written as an `.mdx` file. Regular prose
works exactly like you'd expect, with *emphasis*, `inline code`, and
[links](https://example.com).

## Math

Inline math like $E = mc^2$ renders with KaTeX, and so do block equations:

$$
\frac{\partial u}{\partial t} = \alpha \nabla^2 u
$$

## Code

Fenced code blocks get syntax highlighting automatically, by language:

```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```
